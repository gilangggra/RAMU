# Aturan Git & Remote Repository

- **DILARANG KERAS menjalankan `git push` secara otomatis.**
- Pengguna yang memegang kendali penuh atas `git push` ke remote repository.
- Asisten hanya boleh melakukan pengecekan status, diff, dan commit lokal jika diperlukan.
- Jangan pernah menjalankan `git push` kecuali ada perintah atau izin tertulis secara eksplisit dari pengguna.
